## 3. Binago ang basa ng simbolo (hindi napatunayan ng legend)
- **DITL-03F row 25 / 26 BOILER EMERGENCY TRIP P.B.(1)(2) (N.C.) -> "⊔" -> OR -> NOT:** basa dati = 2 s pulse, kaya laging ON ang trip. beta.3: ang "⊔" sa N.C. contact = ang contact (level). Wala ang "⊔" sa legend DITL-00: interpretasyon ito, hindi napatunayan. Resulta: trip kapag parehong pinindot ang dalawang button.

## 4. Estado ng DITL 150 na hindi galing sa snapshot (palagay)
- AUX. LOP ng BFWP: standby (walang screen).
- MAIN STM TO AUX / AUX STEAM HEADER / GLAND valves: bukas; drains at emergency drains: sarado; FAB A silencer valve: sarado; FAB A outlet: bukas; coal silo outlet: bukas.
- May ebidensya: extraction MOV (4.PNG MVTS 99~100 %), HP / LP bypass (5.PNG 1.1 / 1.3 %), spray (03.png / 4.PNG), oil burners out (6.PNG).

## 5. Hindi pa isinasaalang-alang
- Boiler at turbine physics (fuel -> heat -> steam -> pressure -> MW): wala pa; ang plant model ay per loop lang.
