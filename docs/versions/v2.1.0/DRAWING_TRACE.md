# 2.1.0 — Trace bago ang engine change (PROJECT_RULES 5c)

## beta.6 — "Start at 150 MW": anchor ng plant model sa sandali ng load

- **Saklaw:** plant model lang (`src/analog/engine/plant.js`, `hmi-op.js`). Walang gate, selector, PID o link ng drawing na binabago.
- **Basehan:** ang HMI snapshot ng control room (`document-references/hmi-snapshot-sample.zip`, `docs/hmi/operating-points.json`, CLAUDE.md 4: "ang PV, posisyon ng valve at mode sa snapshot ang tunay na operating point"). Ang `AN_HMI_AI` (transmitter value ng full-load screens) ay isinusulat na sa AI block simula 2.0.0.
- **Nakita (2.1.0-beta.5, PLANT LIVE):** 66 nakakabit na tag sa full-load screens ang lumalayo sa snapshot pagkatapos ng Start at 150 MW + 300 s. Dahilan sa code: ang plant model ng bawat loop na WALANG anchor (13 lang sa `AN_HMI_OP`) ay may sariling steady state `lo + span·(0.5 + sg·K·(u − um)/100)`, at isinusulat nito ang resulta sa transmitter (AI block), kaya napapalitan ang value ng snapshot (hal. ABC-010 AI0256 FIQFW10071: snapshot 498.9 → 550; ABC-008 AI0132 PIFG1085: −16 → 444).
- **Pagbabago:** sa Start at 150 MW, bago tumakbo ang plant model, kinukuha ang PV ng bawat loop mula sa snapshot transmitters (logic lang, plant model OFF sandali). Pagkatapos, ang plant model ng loop ay naka-anchor: ang KASALUKUYANG utos sa valve (u) → ang PV ng snapshot. Ang gain ay limitado gaya ng 13 static anchor (`pr.Ka`). Hindi ginagalaw: loop na may static anchor, drum level (integrating), loop na may parallel valve o measurement na kahati sa ibang sheet, flow loop na sarado ang valve (u < 2 %) o 0 ang flow sa snapshot (hal. oil burner na hindi gamit: ang isolation valve ang sarado, hindi ang control valve).
- **Reset:** ang anchor na ito ay nawawala sa Reset (cold start = gaya ng dati).
- **Patunay na kailangan:** `tests/regress/hmi_op.js` (7 / 7 pa rin), `reset.js` (0 differ), `tests/engine/isolated.js`, scenarios (244 / 0), at bagong bilang ng mismatch sa PLANT LIVE.
- **Dagdag (ABC-008, 7.PNG):** ang IDF hydraulic coupling PICFG108 (A, 46.1 %) at ang IDF inlet damper PICFG108A (M, 99.1 %) ay nasa iisang ID fan: SERIES. Sa drawing, pinipili ang isa (HYDRAULIC / DAMPER CONTROL SELECT, FF M.0202). Ang plant model ng parallel valve (sum) ay mali para dito: ang tugon ay produkto ng dalawang bukas (46.1 % × 99.1 %). Sa 150 MW: M.0202 = 1 (selected), PICFG108 AUTO 46.1 %, PICFG108A MAN 99.1 %. Ang MV preset 13 % ng drawing (M.020E, TPS sa pagtakbo ng ID fan) ay pumapalit sa MV habang naglo-load; ibinabalik ang MV ng snapshot pagkatapos ng 10 s (sa planta, tumatakbo na ang fan).
- **Dagdag (ABC-010, 03.png):** ang drum level DLT ay may pressure compensation (drum pressure PT-BR1001-1 AI0128) at ang FW flow ay may temperature compensation (TIFW1160). Ang plant model ng level / flow loop ay sumusulat sa LAHAT ng AI na may epekto sa PV (sensitivity ≥ 30 %), kasama ang pressure / temperature ng compensation; kaya ang drum pressure ay bumababa sa 0 at ang FW temperature ay umaakyat sa 300 °C. Ayos: ang plant model ay susulat lang sa AI na kapareho ng unit ng PV (mm, T/H ...). Ang compensation input ay ibang measurement (sariling transmitter, sariling value).

## beta.10 — Start at 150 MW: SV, valve position ng snapshot, parallel valves

- **SV:** ang SV ng snapshot ay isinusulat kung saan ito isinusulat ng faceplate (`src/ui/hmi/hmi.js` svSet): ang SV net kapag input, o ang operator leg (B) ng SV switch. Dati, SV net lang, kaya 0 ang SV ng TICHR1002 (snapshot 541) at ng iba.
- **SV ng loop na wala sa snapshot:** kapag ang loop ay hindi REMOTE sa snapshot, operator SV = PV habang galing pa sa snapshot ang PV (steady state sa full load). Dati 0, kaya itinutulak ng PID ang valve sa 0 / 100 % (ABC-029 PICDO1008, ABC-031 LICCD1110A, ABC-035 LICHD11051).
- **Valve position ng snapshot:** 39 controller na may valve sa full-load screens pero wala sa `AN_HMI_CTL` (hal. LICCD1110A LCVMU1110 14.0 % A, FICCD1120 0.1 % A, PICDO1008 85.7 % A, TICLO1002 53.1 % R): idinagdag ang MV at mode (`docs/hmi/operating-points.json`, abcTag + valve).
- **Anchor:** ginagamit ang MV ng snapshot (hindi ang MV na gumalaw habang naglo-load). Parallel valves sa iisang PV: kasama na; ang kabuuan ng mga MV, at ang valve na kabaligtaran ang ACT ay ibinabawas (ABC-031: make-up LICCD1110A nagpapataas ng level, dump LICCD1110B nagpapababa). Hindi i-a-anchor kapag ang kabuuan ay nasa 100 % (walang slope).
- **First stage pressure (ABC-052):** ang REMOTE SV ng LP bypass PICHR1003 = HS(7.6, 5.1 + LN12(average ng AI0883 ~ AI0885, PT-ST1001-1/2/3)). Wala ito sa screen; mula sa SV ng snapshot 36.0 (5.png): LN12 = 30.9 → 96.8 kg/cm2 (LN12 sinukat sa engine: 90 → 28.72, 100 → 31.92).
- Hindi isinusulat ang SV = PV kapag ang valve ng loop ay nasa 0 o 100 % sa snapshot (nasa limit ang loop, hindi PV = SV; hal. ABC-032 FICCD1120 min-flow valve 0.1 % habang 380 T/H ang flow).

## beta.11 — Start at 150 MW: FW, coal, boiler master, air

- **Drum level (ABC-010):** 03.png FW 499.1 T/H, main steam 474.1 T/H. Ang 25.0 T/H ay umaalis sa drum bukod sa main steam (blowdown at iba pa). Ang integrating model ay may "loss" na kinukuha sa snapshot sa load (`pr.integLoss`), nawawala sa Reset. Dati, ang FW ay bumababa sa 474 para tumayo ang level.
- **Coal feeder feedrate (ABC-004A):** MIF-CL1061-A / B / C = STN101 AI0480 / AI0512 / AI0544 (I/O list), 11.png 29.0 / 29.1 / 28.9 T/H; wala sa 150 MW table, kaya 0 ang coal master PV.
- **HS-COAL oil valve inputs (ABC-004A):** 8 input na text lang sa drawing ("A-BNR SUPPLY OIL" + "VALVE(1)/(2) CLOSE"). Sa full load, patay ang oil burner (6.PNG: oil flow 0, FIC-OM M 0 %) kaya sarado = 1. Ang wire ay hinahanap sa text, gaya ng UAT. HS-COAL = AUTO (11.png: FIC-CM REMOTE 73 %, sumusunod ang feeders sa SV 29.1).
- **MW demand / boiler master (ABC-001A ~ 001D):** HIC-BM = PIC-COBM MV + LN54(MW demand SI0226). Ang MW target ay ang HIC-ULD (MAN station), na sumusunod sa operator input (COS SI0243) sa AUTO. Sa 33.PNG: TARGET MW 150.0, MW HIGH LIMIT 238.4 (clamp sa range ng station), LOW LIMIT 0.0, CHANGE RATE 3.0 MW/min. Ang MAN stations ay isinusulat na sa load. Ang mga RATE / LAG ng drawing ay inilalagay sa steady state (naabot na ang input), dahil steady ang planta sa full load; dati, 50 min bago umabot sa 150 MW ang MW demand (3 MW/min).
- **PID output:** isinusulat ang output AT ang integral (`I`) para manatili kapag PV = SV (PIC-COBM 0.8 %).
- **Anchor ng measurement na kahati sa ibang sheet (main steam pressure: PIC-COBM ABC-001C, PICMS1006 ABC-050, PICMS1002 ABC-013):** pinapayagan na sa load; ang offset ay kinukuha minsan lang, kaya gumagana pa rin ang epekto ng ibang controller.
- **Hindi pa:** FIC-CF (ABC-004A). Ang PV = 1/3 × kabuuan ng 3 feeder demand (drawing, "A = 1 / 3"); ang SV ay galing sa coal master. Sa snapshot: PV 81.2, SV 81.2, MV 33.1; sa sim: PV 40, MV 100. Kailangan pa ang trace ng coal calorie correction at ng unit sa pagitan ng FIC-CM MV at FIC-CF SV.
