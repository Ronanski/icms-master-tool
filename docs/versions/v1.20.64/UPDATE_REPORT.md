# v1.20.64 (Beta) — Faceplate ayon sa DCS ng planta + coverage ng input / output

**Problem:** (user, may larawan ng tunay na faceplate: HP T/B bypass steam press. ctl, S/B steam inlet press. control) Ang faceplate ng app ay hindi pareho ng sa planta; at ang test ay dapat sumakop sa lahat ng input, output, behavior at control.
**As Found (sa larawan):** pamagat sa itaas; bar graph (PV cyan, SV dilaw) na may scale; kahon ng PV at SV (may unit); patayong selector **R / A / M** (R ay nasa loop lang na may REMOTE; ang iba ay A / M lang), ang aktibo ay may kulay (A dilaw, M berde) at ◀; scale ng MV na may pointer; kahon ng MV (%); pangalan ng tag sa berdeng bar sa ibaba.
**Work Done (UI lang, walang ginalaw sa engine):** `src/ui/hmi/hmi.js` at `hmi.css`: ganito na ang itsura. R = REMOTE (SV galing sa logic, AUTO talaga), A = AUTO na SV ng operator (LOCAL; kapag galing sa R ay lumalabas sa REMOTE), M = MANUAL. Ang SV at MV ay mga kahon na mismo (MV ay ang aktuwal na MV; naka-disable sa A / R). Nasa "Engineering" (collapsible) ang mga signal ng drawing, SV − / +, MV 0 / 50 / 100, mga mode input (.REM .LOC .MAN) at trend. Nasa ilalim ng faceplate pa rin ang FORCE MANUAL at ang babala ng interlock.
**Coverage (`tests/scenarios/cone.js`):** bawat external input ay binabago (digital 0 / 1, analog mababa / gitna / mataas) sa 14 panimulang kondisyon at tinitingnan kung aling net ang gumagalaw, laban sa istruktura ng drawing. ABC-007: 29 input, 17 output, lahat ay may epekto; walang net na gumalaw na wala sa daloy ng drawing.
**Na-check:** panel_sync 0 FAIL, faceplate 68 controller OK, force_manual 68 / 68, scenario UAT 156 / 156 (gamit ang bagong R / A / M), `npm run check`.
**Hindi pa:** (1) ang pagpindot sa R / A / M ay hindi pa nagpapa-pulse ng .REM / .LOC / .MAN input ng drawing (sa planta, ito ang HMI command; ang M.018D SET rule ay gumagamit nito); (2) ang pamagat ay galing sa data ng PID (hal. "PAF/SAF AIR FLOW CONTROL"), hindi laging ang pamagat na nasa faceplate ng planta; (3) alarm marker (berdeng guhit) sa bar graph; (4) hindi pa nasusubukan sa device.
