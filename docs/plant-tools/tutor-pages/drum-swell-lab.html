Saan galing ang mga numero

  • Drum level: normal 0, H +127, HH +254, L -100, alarm LL -178 mm (alarm list LT/LS-BR1001).
  • MFT: drum level above +254 o below -254 mm, 2 of 3 transmitters, 5 s (ABC-010, DITL-03E). Ang LSHH/LSLL switches ay alarm lang. Naka-block ang HH trip ng 600 s pagkatapos ng turbine trip, 52G o 52L open (DITL-03E).
  • MCR steam 460 t/h (FHI Tab 2). Drum pressure 145 kg/cm2 = SH outlet 129 + SH pressure drop 16 (FHI Tab 2, 3; kinuwenta ko).
  • 1-element level control below about 230 t/h, 3-element above (PR-OPE-5003).
  • Generic, hindi plant data: ang bilis ng pagbabago (gaano kabilis tumaas ang level, gaano kalaki ang swell) ay pinasimple para makita ang hugis ng response. Ang direksyon at pagkakasunod ang tama, hindi ang eksaktong segundo.
