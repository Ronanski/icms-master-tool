Galing sa docs ng planta: 3600 rpm = 60 Hz; generator 13.8 kV; isinasara ang 52G kapag nasa alas-12 ang synchroscope; medyo mas mataas ang Hz at boltahe ng generator kaysa grid para hindi bumaligtad ang daloy; ang relay 25 (sync check) ang pumapayag; ang ASD (automatic synchronizing device) ang gumagawa nito nang awtomatiko; unang load 4.5 MW (start-up procedure PR-OPE-5002, turbine at electrical study notes). Generic, hindi plant data: ang mga tolerance na ginamit dito (bilis within 0.2 Hz, boltahe within 0.3 kV, karayom within 10 degrees) at ang simulang 59.60 Hz at 12.9 kV. Ang ikot ng gulong ay pinabagal para makita ng mata; ang ikot ng karayom ay totoong bilis ng diperensya.
