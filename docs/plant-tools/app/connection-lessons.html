Connection Lessons

One connection of the Unit 1 control logic per lesson. Switch the condition and see what the logic does to the station. Then answer the question that runs backwards: from what you see to the cause.

Source of every lesson: the analog logic sheet and memory address shown in it, as recorded in the simulator's drawing trace (docs/OPERATOR_GUIDE.md and docs/versions/v2.2.0/DRAWING_TRACE.md).
