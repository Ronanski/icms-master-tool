Plant data core: notes and document sources

Isipin mo ang masterlist ng empleyado ng planta, pero para sa bawat signal. Bawat tag ay may iisang "ID card". Doon nakasulat kung ano ito, saan galing, saan dumadaan, saan pumupunta, at ano ang ginagawa nito. Lahat ng ibang tool ay sa ID card na ito kukuha, kaya iisa lang ang totoo at hindi na nagkakasalungat.

TAG TCSAI1005 PANGALAN Max turbine load up rate set RANGE 0.0 ~ 5.0 %/min GALING TCS (Hitachi) → DCS AI0421 DAANAN hard-wired, TCS panel → MPL → FCS card PUPUNTA trend, HMI ... (logic: hahanapin sa ABC/DITL) GAMIT monitor / control / interlock / trip DOKUMENTO DCS loop list STN101, TCS HMI list

Halimbawa lang ang ilang linya (ang "DAANAN" at "PUPUNTA" ay pupunuin mula sa wiring list at logic). Ang tunay na laman ay galing sa mga dokumento ng planta.

Paano bubuuin

  1. Pagsamahin ang lahat ng listahan sa iisang file, isang linya bawat tag.
  2. Hanapin ang kulang at ang nagkakasalungat (hal. magkaibang range sa dalawang listahan) at ilista kung aling dokumento ang tama.
  3. Ikabit ang bawat tag sa logic sheet na gumagamit nito.
  4. Gawing basa ng lahat ng tool: Tag Lookup muna, tapos simulator, tracer at 3D.
